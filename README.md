# Global Seismic Trends

## About the Project
Global Seismic Trends is a data analysis project that explores global earthquake activity using data collected from the USGS Earthquake API.
The project analyzes earthquake patterns based on magnitude, depth, location, time, tsunami activity, and other earthquake characteristics.

## Objectives
	•	Collect earthquake data from the USGS API
	•	Clean and prepare the data for analysis
	•	Store and analyze the data using MySQL
	•	Perform SQL-based analysis
	•	Build an interactive Streamlit dashboard
	•	Identify useful patterns and insights from earthquake data

## Technologies Used
	•	Python
	•	Pandas
	•	MySQL
	•	SQLAlchemy
	•	Plotly
	•	Streamlit

## Dashboard
The Streamlit dashboard provides:
	•	Key earthquake statistics
	•	Magnitude trends
	•	Geographic analysis
	•	Year-wise earthquake activity
	•	Tsunami analysis
	•	Country-wise earthquake activity
	•	SQL analysis results
